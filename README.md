# Dark Science Division

Independent research and engineering by **Sam Flynn**. Local-first, deterministic, governed systems.

## Product families

- **PRAXIS** — probabilistic risk analysis (Bayesian updating, fault trees, Monte Carlo, cascade/CCF).
  Architecture and worked examples are public ([praxis-titan](https://github.com/darksciencedivision-ctrl/praxis-titan)); the `praxis_core` engine is commercial ([Praxis-engine](https://github.com/darksciencedivision-ctrl/Praxis-engine)).
- **NEO-LAB** — deterministic control plane for orchestrating role-separated local LLMs ([Neo-V3](https://github.com/darksciencedivision-ctrl/Neo-V3)), with supporting tools ([ollama-dialog-broker](https://github.com/darksciencedivision-ctrl/ollama-dialog-broker), [URI](https://github.com/darksciencedivision-ctrl/URI)).
